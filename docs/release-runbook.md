# 《合成能量》发布上线操作手册（Runbook）

> 本手册为**可执行 SOP**，把分散的合规要点转化为「按点击顺序照做」的步骤。
> 依据：项目调研文档 `docs/publish-checklist.md`（事实来源）。本手册不重复调研分析，仅给操作路径。
> 数据来源：抖音开放平台官方文档、腾讯云备案相关规定、工信部备案要求，以及 2025–2026 行业经验。
> ⚠️ 互联网政策更新频繁，凡标注「需以官方最新口径为准」处，请操作前在对应控制台/管局复核。

---

## 顶部速览

**适用范围**：本手册覆盖本次落地的两项实操——

- **② 域名 ICP 备案实操**（对应发布清单「阶段 2 域名 ICP 备案 / 线 B」）：购买腾讯云轻量应用服务器（大陆节点、最低配）仅作备案接入 → 在腾讯云备案系统提交 `kejingbbao.cn` 个人 ICP 备案（身份证 / 真实性核验单 / 人脸核验等）。
- **③ 抖音开放平台后台合规设置**（对应发布清单「阶段 1 后台合规设置」）：在开发者控制台勾选确认「自审自查报告」；提交「适龄提示分段」（休闲合成类一般 8+ 或 12+）。

**一句话路径**：

- **线 A（发布）**：个人主体 + 软著（已就绪/进行中）+ 无版号通道（游戏备案→ICP 核准）+ 版本提审（1–3 工作日）→ 上线。
- **线 B（备案提速）**：腾讯云轻量服务器作备案接入 → 域名 ICP 备案（1–4 周）→ EdgeOne 加速区域切含中国大陆。

**总体前置依赖（开始前必查）**：

1. 📌 **软著（计算机软件著作权登记证书）**：抖音强制要求，创建小游戏须提供；小游戏名称须与软著登记名称（或简称）基本一致，软著著作权人须与平台主体名称完全一致（不一致需上传授权书）。
2. 📌 **域名实名一致**：`kejingbbao.cn` 注册者须 = 备案人本人（当前已实名，须核对一致 ✅）。域名注册者与备案主办者不一致 → 初审直接驳回。
3. 👤 **本人账号实名**：抖音开放平台个人开发者账号主体认证（手机号 / 银行实名，**切勿误选"企业"**，平台不支持主体变更）；腾讯云账号个人实名（用于买服务器、提备案）。
4. 👤 **本人证件与联系方式**：本人身份证正反面、本人实名手机号、可用邮箱。
5. 📌 **变现模式锁定**：坚持不接内购（IAP），仅保留广告（IAA）或无变现 → 锁定「无版号」通道。

**分工图例**：👤 = 必须用户本人操作（刷脸 / 签字 / 按手印）　🛠️ = 可团队（主理人+工程师）代填 / 代传 / 代跟进

# Part 1 · 域名 ICP 备案实操 SOP（线 B）

> 目标：从「购买腾讯云轻量服务器」到「拿到 ICP 备案号」。
> 关键结论：ICP 备案**必须**有一台境内服务器作「备案接入商」；Vercel 等境外托管无法直接备案（系统会因解析 IP 在境外直接驳回）。买腾讯云轻量应用服务器（大陆节点、最低配）**仅作备案接入、不转移业务流量**是可行且推荐的标准做法。

## 前置：备案材料清单（先按清单备齐）

| 材料 | 说明 | 负责人 |
|---|---|---|
| 个人身份证 | 正反面原件照片 / 彩色扫描（边角完整、无反光、在有效期内≥3 个月）。 | 👤 用户 |
| 域名实名信息 | `kejingbbao.cn` 注册者须 = 备案人本人（核对一致 ✅）。 | 👤 用户确认 / 🛠️ 核对 |
| 手机号、邮箱 | 本人实名手机号、可用邮箱。 | 👤 用户 |
| 真实性核验单 | 部分省份要求本人**手写签名 + 按手印**。 | 👤 签字按印 / 🛠️ 起草 |
| 人脸核验 | 手机在线完成（主流方式）；部分省份/场景需幕布拍照或手持证件照。 | 👤 本人刷脸 |
| 属地特殊材料 | 非本省户籍可能需居住证/社保证明；如备案网站>5 个（如广东）需网站建设方案书；广东/河南等需备案信息真实性承诺书（手写签名+按手印）。 | 👤 按省份补 / 🛠️ 起草 |

⚠️ **重大前置坑**：先核对 `kejingbbao.cn` 域名实名注册者 = 你本人。不一致 → 初审直接驳回，重来。

## 步骤（逐步点击清单）

1. **👤 腾讯云账号实名（个人）**
   - 打开腾讯云控制台（cloud.tencent.com）→ 右上角头像 → 账号信息 / 实名认证 → 选择「个人」认证 → 按提示完成（姓名+身份证号+人脸/银行卡验证）。
   - ⚠️ 个人主体，勿选企业；备案主体必须与抖音主体、域名注册者三者一致。

2. **👤 购买腾讯云轻量应用服务器（仅作备案接入）**
   - 控制台 → 产品 → 轻量应用服务器 → 新建 / 购买。
   - 地域：**选中国大陆节点**（如上海 / 广州 / 北京，按你就近或管局属地选）。
   - 配置：**最低配**（入门型即可，无需高配，仅作备案接入，不承载业务流量）。
   - 系统镜像随意（备案接入不依赖具体业务）；计费按量或包月均可（备案期间需持续有境内 IP 解析）。
   - 完成支付并等待实例创建就绪。
   - ⚠️ **不可用 Vercel / 任何境外服务器直接备案**——系统会因解析 IP 在境外直接驳回。
   - ⚠️ 该轻量服务器仅作接入；业务流量仍走 Vercel + EdgeOne 全球节点，不要迁移业务。

3. **🛠️/👤 进入腾讯云备案系统**
   - 控制台 → 顶部/左侧搜索「备案」或「网站备案」→ 进入「ICP 备案」控制台（备案系统）。
   - 路径示例：我的备案 → 新增备案 / ICP 备案 → 开始备案（首次备案选「新增网站」/「新增备案」）。
   - 🛠️ 团队可在此代填主体信息、网站信息、上传材料并把关规范性；👤 最终需本人确认提交并完成人脸核验。

4. **🛠️ 填写主体信息（个人）**
   - 主办者性质：个人；姓名、证件号、手机号、邮箱须与身份证、域名实名**逐字一致**。
   - 通信地址、应急电话按实填写（属地特殊要求见步骤 6）。
   - ⚠️ 个人备案「网站备注 / 内容」**不得涉"盈利 / 经营 / 经营性"**——个人不可经营性，否则驳回。

5. **🛠️ 填写网站信息（域名 = kejingbbao.cn）**
   - 域名：填写 `kejingbbao.cn`（已实名，注册者=本人）。
   - 网站名称：按规范起名，避免敏感词；⚠️ 名称含敏感词或不符命名规范会驳回。
   - 服务内容：选「博客 / 个人空间 / 其他」等非经营性类别（与游戏业务一致表述为静态展示/接入用途，避免经营性描述）。
   - 服务器：自动关联步骤 2 购买的轻量应用服务器（备案接入商=腾讯云）。

6. **👤 准备属地特殊材料（按所在省份管局规则）**
   - 核对你备案省份管局要求：非本省户籍可能需居住证/社保证明；广东/河南等需「备案信息真实性承诺书」（手写签名+按手印）；广东备案网站>5 个需「网站建设方案书」。
   - 🛠️ 团队可起草核验单、承诺书、方案书模板；👤 本人签字/按手印/提供居住证等。
   - ⚠️ 属地材料不齐是常见驳回项（广东/湖南/天津等尤甚），提前查清本省规则。

7. **🛠️/👤 上传材料**
   - 上传身份证正反面（清晰、边角完整、无反光）。
   - 上传真实性核验单、承诺书、属地材料（按步骤 6）。
   - ⚠️ 身份证模糊/反光/边角不全是**最常见驳回原因**；扫描件保证四角入镜、光线均匀。

8. **👤 人脸核验（必须本人）**
   - 在备案系统触发「真实性核验」→ 用**本人手机**扫码或点开核验链接 → 按提示完成在线人脸核验（张嘴/眨眼等动作）。
   - 部分省份/场景需「幕布拍照」或「手持证件照」，按系统提示执行。
   - ⚠️ 人脸核验失败需重做；确保光线充足、本人操作、未使用照片翻拍。

9. **🛠️/👤 提交初审**
   - 核对全部信息无误 → 提交腾讯云接入商初审。
   - 腾讯云初审 **1–3 工作日**：可能电话核实（保持手机畅通），或退回补正（🛠️ 团队跟进）。
   - ⚠️ 初审可能联系应急电话核身，确保填写的手机号/应急电话可接通。

10. **🛠️ 管局审核（等待）**
    - 腾讯云初审通过后提交省通信管理局 → 管局审核 **通常 5–20 工作日**（多数省份 7–20），整体约 **1–4 周**。
    - 🛠️ 团队跟踪进度；管局可能短信核验（工信部备案短信核验），👤 收到短信须在规定时限内完成确认。
    - ⚠️ 管局短信核验链接有时效，超时未确认会被打回，留意手机短信。

11. **👤/🛠️ 取得 ICP 备案号**
    - 审核通过 → 在备案系统 / 管局通知取得 **ICP 备案号**（格式如「京ICP备XXXXXXXX号-X」）。
    - 记录备案号，通知团队用于后续 EdgeOne 切境内加速（线 B 阶段 4）。
    - ⚠️ **IP 核查坑**：工信部会定期 IP 核查，若备案后域名长期解析到境外 IP，可能注销备案。备案通过后应尽快执行线 B（EdgeOne 切境内加速）使域名有境内可达节点；或至少保持轻量服务器作为接入并长期有境内 IP 解析记录（可在轻量服务器放一个简单可达页面 / 用其做备案接入并保持解析）。

## 常见驳回原因与对策（速查）

| # | 驳回原因 | 对策 |
|---|---|---|
| ① | 身份证模糊/反光/边角不全 | 重拍：四角入镜、无反光、有效期内≥3 月 |
| ② | 域名未实名或实名注册者≠备案主办者 | 先核对并修正 `kejingbbao.cn` 实名信息一致 |
| ③ | 主体信息（姓名/证件号）与证件不符 | 逐字核对，一个字不对即驳回重来 |
| ④ | 网站名称含敏感词/不符命名规范 | 按规范改名，避免敏感词 |
| ⑤ | 真实性核验单未签名/未按手印/未盖章 | 按省份要求本人手写签名+按手印 |
| ⑥ | 人脸核验失败 | 光线充足、本人手机操作、勿翻拍 |
| ⑦ | 个人备案备注/内容涉经营性 | 改为非经营性表述，个人不可经营性 |
| ⑧ | 属地特殊材料未满足（居住证/方案书等） | 提前查清本省管局要求并补齐 |

# Part 2 · 抖音开放平台后台合规设置 SOP（线 A 后台合规）

> 目标：进入开发者后台 → 勾选确认「自审自查报告」→ 找到「适龄提示」设置 → 填写分段值。
> 依据（A3 内容合规）：自审自查报告自 2024-07-11 起可在控制台**直接勾选确认**（无需单独上传）；适龄提示自 2021-06-01 起**强制**，须提交分段 8+ / 12+ / 16+，休闲合成类一般 8+ 或 12+。

## 步骤（逐步点击清单）

1. **👤 登录开发者后台**
   - 打开抖音开放平台（developer.open-douyin.com 或 partner.open-douyin.com）→ 用**个人开发者账号**登录（须已完成主体认证，且为「个人」非「企业」）。
   - 进入「小游戏」管理 / 我的小游戏，选择《合成能量》对应小游戏（引擎=原生 `tt.*`，名称与软著一致）。

2. **🛠️/👤 进入合规 / 资质设置环节**
   - 在游戏管理后台找到「游戏备案 / 资质信息 / 合规设置」相关入口（提交游戏备案无版号时进入的合规确认环节）。
   - ⚠️ 控制台菜单标签可能随版本调整；以后台实际界面「合规 / 自审 / 资质」区为准。若找不到，使用后台搜索框搜「自审」「适龄」「备案」。

3. **👤 勾选确认「自审自查报告」**
   - 在合规确认处找到「自审自查报告」勾选项 → 阅读平台自审标准 → **勾选确认**「本游戏功能/内容满足平台自审标准」。
   - ⚠️ 自 2024-07-11 起为**直接勾选确认**，无需单独上传文件；须真实确认，虚假确认属合规风险。
   - 👤 此勾选代表主体责任确认，建议用户本人操作；🛠️ 团队可协助定位入口并核对勾选项含义。

4. **👤/🛠️ 填写「适龄提示」分段值**
   - 在资质/合规信息中找到「适龄提示」字段 → 提交分段值。
   - 可选档位：**8+ / 12+ / 16+**。
   - 本游戏（休闲合成类）建议填 **8+ 或 12+**（一般取 8+；若含实时房间对战社交元素，倾向 12+ 更稳妥）。
   - ⚠️ 适龄提示**强制**（2021-06-01 起全面实施），未填或错填会被驳回；分段须与实际内容匹配。

5. **🛠️ 同步完善关联合规材料（避免 P0 红线驳回）**
   - 隐私政策：平台提供模板，完善后须独立文本（非用户协议一部分）、首次运行前弹窗提示、≤4 次点击可达、含收集目的/方式/范围/处理者联系方式、披露第三方 SDK；协议内游戏名/主体名与后台一致（不可自定义编辑）。🛠️ 团队起草，👤 确认。
   - 用户协议：建议提供（隐私政策独立于用户协议）。
   - 防沉迷/未成年人保护：本游戏含实时房间对战（社交）→ 须处理实名/防沉迷，可通过 `tt.login` 登录→实名或平台统一能力。🛠️ 团队接入，👤 确认逻辑。
   - ⚠️ 隐私/用户协议不规范属 **P0 红线**，直接驳回；含社交功能却未接实名/防沉迷，面临下架或监管处罚风险。

6. **👤/🛠️ 保存并提交**
   - 核对自审自查报告已勾选、适龄提示已填、隐私政策/用户协议已就绪 → 保存。
   - 该合规设置通常在「游戏备案（无版号）」提交环节一并生效；🛠️ 团队跟进「游戏备案」审核，👤 配合驳回补正（驳回后 72h 内查看违规截图与条款链接并确认整改）。
   - ⚠️ 同一游戏连续两次不通过会被标记「高违规风险」，后续审核周期翻倍——一次做对。

## 文末 · 需以官方最新口径为准的不确定点（操作前复核）

> 以下取自 `publish-checklist.md` 附录，存在政策/口径变动风险，**操作前请向对应官方渠道复核**，本手册不构成法律意见。

1. **「实时房间对战」是否触发版号要求**：休闲合成无内购通常豁免，但联网玩法口径需抖音开放平台确认；若被认定「强联网/棋牌」类存在版号争议。
2. **平台「ICP 核准 / 游戏备案」是否硬性要求后端域名 `kejingbbao.cn` 已完成工信部 ICP 备案**：抖音白名单本身仅校验 HTTPS 可达性、不强制备案，但游戏级合规口径需确认。
3. **所在省份管局对个人备案的具体属地材料要求**：核验单 / 承诺书 / 居住证 / 网站建设方案书等，各省规则不同（广东/河南/湖南/天津等尤需注意）。
4. **纯境外源站（Vercel）+ EdgeOne 境内加速的跨境回源质量是否可接受**：源站在境外、加速区域含大陆时，用户→EdgeOne 境内节点→跨境回源 Vercel，回源延迟较高、效果不保障；若否，是否需迁部分源站至境内。
5. **控制台菜单路径时效性**：自审自查报告、适龄提示、游戏备案等后台入口标签可能随平台版本调整，以操作当时后台实际界面为准。
