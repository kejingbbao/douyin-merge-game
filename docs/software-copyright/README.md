## 五、提交步骤摘要（参考 `docs/software-copyright-materials.md`）

1. **线上填报**：登录中国版权保护中心「中国版权服务」→ 版权登记 → 软件著作权登记（<https://www.ccopyright.com.cn>）；或个人可由抖音开放平台提供的火山引擎软著特惠入口进入。
2. **上传材料**：上传源码鉴别材料（`source-code.md` 打印件/PDF）、软件说明书（`design-manual.md`）、申请表，并按系统提示上传身份证复印件、非职务开发保证书等。
3. **实名认证**：在中国版权保护中心完成**个人账号实名认证**（👤 本人操作）。
4. **缴费/受理**：个人申请官费已**免费**；代理加急另计（可选）。
5. **等待审查**：普通周期约 **1–3 个月**；审查通过下发《计算机软件著作权登记证书》（电子/纸质）。
6. **获证后**：进入抖音提审流程（创建小游戏、提交游戏备案/无版号通道、上传软著）。
