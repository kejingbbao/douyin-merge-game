## 二、我们如何收集与使用您的信息

本游戏仅在必要、最小范围内收集信息，用于提供游戏服务、对战匹配、排行榜与合规实名。我们**不会**收集与游戏功能无关的个人敏感信息。

### 2.1 信息收集范围与用途

| 信息类别                      | 来源 / 方式           | 用途                                       | 是否必填                      |
| ------------------------- | ----------------- | ---------------------------------------- | ------------------------- |
| 抖音 OpenID、昵称、头像           | 经 `tt.login` 授权获取 | 账号标识、对战房间匹配、排行榜展示（公开仅显示昵称与分数，不展示 OpenID） | 使用社交/对战/排行榜功能时必填；纯单机合成可跳过 |
| 游戏进度与对战记录                 | 本地生成 + 上传云端       | 天梯榜积分、房间战绩、断点续玩、防刷分校验                    | 开启云端功能时收集                 |
| 设备信息（机型、系统版本、网络类型等基础设备标识） | 抖音运行时提供           | 性能适配、崩溃排查、反作弊                            | 自动收集                      |
| 行为数据（游戏内操作、对局时长、广告曝光）     | 运行时统计             | 产品优化、广告效果统计（IAA）                         | 自动收集，可关闭                  |

### 2.2 明确不收集的信息

为遵守平台数据权限红线，本游戏**不收集**以下与游戏功能无关的信息：

- 通讯录、相册、地理位置、麦克风、摄像头等非必要权限对应数据；
- 生物识别、健康、宗教、政治观点等个人敏感信息；
- 任何与 gameplay 无关的第三方账户凭证。

> 如平台未来拟将行为数据用于个性化推荐/广告投放，本政策将**事先明示并提供关闭入口**（ checklist A3 数据权限红线）。

### 2.3 第三方 SDK / 服务提供方披露

本游戏接入以下抖音开放能力，相关数据由对应服务提供方按各自隐私政策处理：

| 第三方能力                 | 提供方                                                     | 涉及数据              | 用途        |
| --------------------- | ------------------------------------------------------- | ----------------- | --------- |
| 登录授权 `tt.login`、实名    | 北京微播视界科技有限公司（抖音）                                        | OpenID、昵称、头像、实名信息 | 账号与合规实名   |
| 分享 `tt.share`         | 抖音                                                      | 分享内容（分数截图）        | 用户主动分享战绩  |
| 广告（Banner / 激励视频，IAA） | 抖音流量主                                                   | 设备标识、广告曝光/点击      | 广告展示与结算   |
| 云端存储（游戏进度 / 对战记录）     | Upstash（Redis，经域名 `kejingbbao.cn` 回源 Vercel Serverless） | 上述 2.1 游戏数据       | 排行榜与对战持久化 |

## 三、信息的存储、期限与安全

### 3.1 存储地点与期限

- **存储地点**：游戏进度与对战记录存储于 Upstash Redis（境外节点），经已加白名单域名 `kejingbbao.cn` 回源 Vercel Serverless 处理；账号标识来自抖音服务端。
- **存储期限**：
  - 游戏进度 / 对战记录：自生成起保存至 `账号注销或 6 个月无活动后删除`；
  - 实名 / 账号信息：遵循抖音平台留存规则及防沉迷合规要求留存；
  - 日志类数据：最短必要期限（建议 ≤ 30 天）。
- **超期处理**：到期后自动删除或匿名化处理。

### 3.2 安全措施

- 传输全程 HTTPS（EdgeOne 强制 HTTPS）；
- 分数上报采用 HMAC-SHA256 签名 + 时间戳防重放，后端验签失败即拒绝（防刷分）；
- 对战数据按 OpenID 隔离，最小权限访问控制；
- 定期安全巡检，发现漏洞 72 小时内响应处置。

## 五、未成年人保护

本游戏含**实时房间对战（社交玩法）**，依据平台规范与《关于进一步严格管理 切实防止未成年人沉迷网络游戏的通知》，须落实实名与防沉迷：

1. **实名要求**：使用对战 / 排行榜等联网功能前，须通过 `tt.login` 完成抖音实名认证；未实名用户仅可使用单机合成模式。
2. **防沉迷（青少年模式）**：平台按实名信息自动识别未成年用户并引导进入青少年模式，执行：
   - 每日游戏时长限制（含 `≤1 小时`）；
   - 22:00 – 次日 6:00 禁玩；
   - 本游戏**无内购付费点**，故不涉及充值限额；如未来接入内购须另行合规。
3. **家长监护**：监护人可通过对账号实名信息的管控限制未成年人使用。

> 含社交功能却未接实名/防沉迷，将面临下架或监管处罚风险（checklist A3）。
