## 0. 核心门槛结论（先看这里）

| 问题 | 结论 |
|---|---|
| 个人（自然人）能否独立提审并上线抖音小游戏？ | ✅ **可以**。抖音支持个人主体创建并运营小游戏（非"小玩法"），每个个人主体可创建 25 个小游戏；仅需手机号/银行账户实名认证。无需企业/个体工商户。 |
| 软著是否强制？个人无软著能否上架？ | 📌 **强制**。抖音明确"创建小游戏时须提供【计算机软件著作权登记证书】"，个人无软著无法上线（不同于微信的可选）。须提前申请，个人可自办。 |
| 版号是否必须？ | ✅ **当前不必**。《合成能量》为 2048 式合成 + 震动 + 结束排名 + 天梯 + 实时房间对战，**无虚拟货币、无内购充值点**（按 IAA/无变现处理）。版号仅为"开通内购(IAP)能力的重要凭证"，无内购走"无版号"通道即可上线。⚠️ "实时房间对战"属联网玩法，若被认定为强联网/棋牌类存在版号争议，但休闲合成类无内购通常豁免——**需以抖音开放平台最新答复为准**。 |
| 域名 ICP 备案是否必须买境内服务器？ | 📌 **是，必须有一台境内服务器作"备案接入商"**。Vercel 境外托管无法直接备案（系统会因解析 IP 在境外直接驳回）。买一台腾讯云轻量应用服务器（大陆节点、最低配）**仅作备案接入、不转移业务流量**是可行且推荐的标准做法。 |
| 未备案域名能否先上线？ | ✅ **线 A 可独立推进**：抖音 request 合法域名白名单仅校验 HTTPS 可达性，不强制要求域名已工信部备案；当前 `kejingbbao.cn` 已加白名单 + EdgeOne「全球可用区(不含中国大陆)」免备案可正常运行。但**线 B（境内加速）必须完成域名 ICP 备案**后方可切换。 |

**一句话路径**：
- 线 A（发布）：个人主体 + 软著 + 无版号通道（游戏备案→ICP 核准）+ 版本提审（1–3 工作日）。
- 线 B（提速）：腾讯云轻量服务器作备案接入 → 域名 ICP 备案（1–4 周）→ EdgeOne 加速区域切含中国大陆。

**2026 平台合规新趋势（务必前置到设计）：**
- 分享须用户主动点击、有明确游戏内奖励，禁止自动跳转/弹窗诱导、禁止"分享一次给一次抽奖"无限循环。

- 数据权限红线：禁止读取通讯录/相册/位置等非必要权限；收集行为数据用于推荐/广告须在隐私政策明示并提供关闭。

## A4 技术 / 包体要求

| 维度 | 要求 |
|---|---|
| 运行环境 | 当前为 `tt.*` Canvas 小游戏（已满足）。仅支持 JavaScript，无 DOM/BOM，需自行兼容 `window`（引擎导出一般已含 adapter）。 |
| 包体大小 | 普通小游戏包（未分包）：总大小上限 **20 MB**。分包：整体 ≤20 MB，主包 ≤4 MB，单分包 ≤20 MB；开放数据域 ≤4 MB。 |
| 合法域名白名单 | 须 HTTPS。`kejingbbao.cn` **已在白名单**（✅ 已满足），且 EdgeOne 强制 HTTPS（✅）。 |
| 类目 | 创建时选「游戏」引擎与类目；无版号完成后平台默认「休闲娱乐-游戏」。 |
| SDK 接入 | 开放能力（登录 `tt.login`、分享、广告、支付）按需接入；**支付(内购) SDK 仅在开通内购时需要**（当前无→不接）。 |
| 实时房间对战 | 经已白名单域名 `kejingbbao.cn` 的 WebSocket/HTTP 通信（Vercel + Upstash），域名已在白名单即可，无需额外资质。 |

**常见驳回点（来自平台自审标准 P0/P1）：**
- 名称/软著/版号不一致；隐私/用户协议不规范（P0）。
- 强制授权、反复调起授权、索要非必要权限（P0）。
- 广告违规：banner 遮挡按钮/主场景摆 banner、将看激励视频设为关卡解锁前置、默认勾选观看、阻碍取消（P1）。
- 功能未实现/声明奖励不符实；录屏/分享功能异常。
- 适配问题（刘海屏/挖孔屏）；加载图禁显示进度条、禁非真实数据。

**三列分工（A4）：**

| 【用户必须亲自准备/操作】 | 【可由团队(主理人+工程师)代劳】 | 【注意点与坑】 |
|---|---|---|
| 提供游戏图标、简介、3 张提审截图（含游戏名+实际画面）、加载图（禁进度条/非真实数值）。 | 校验包体 ≤20 MB、配置白名单、接入登录/分享/广告 SDK、实现适龄与防沉迷逻辑。 | 包体超限直接拒；加载图违规是高频驳回点。 |
| 确认不接内购支付 SDK。 | 优化首包体积与启动耗时（影响转化率与取消率）。 | 广告频次/位置违规（P1）易被忽略但会驳回。 |

## A5 审核流程与时长

**流程：** 创建小游戏 → 完善基础信息(名称/图标/简介/资质) → 游戏备案(无版号) → ICP 核准 → 版本提审 → 审核(1–3 工作日) → 发布。

| 阶段 | 时长 | 说明 |
|---|---|---|
| 版本提审 | **1–3 个工作日**（新游首提建议按 3 天预留；老版本更新更快，最快半天）。 | 无官方加急通道，勿信"代加急"。周末有值班。 |
| 游戏备案 / ICP 核准 | 平台仅协助登记，时效依监管实际；此前已需软著等材料齐备。 | 无版号小游戏的 ICP 核准入口在「小游戏备案」审核通过后开放。 |
| 驳回重提 | 周期重新计算。 | 连续两次不通过→标记"高违规风险"，后续审核周期翻倍。 |

**三列分工（A5）：**

| 【用户必须亲自准备/操作】 | 【可由团队(主理人+工程师)代劳】 | 【注意点与坑】 |
|---|---|---|
| 在后台触发版本提审、处理驳回补正。 | 准备提审包、截图、自测项，提交提审并跟进状态。 | 资质不齐（软著/适龄/自审）临时补→重交一次时间全重置；节假日扎堆审核翻倍。 |

## B2 接入要求（关键坑）

| 维度 | 结论与要点 |
|---|---|
| 是否必须境内服务器 | 📌 **必须**。ICP 备案硬性前提：服务器物理节点位于中国大陆境内，且由具备接入商资质的云服务商（阿里云/腾讯云/华为云）作为接入商。Vercel 等境外托管**无法直接备案**，系统会因解析 IP 在境外直接驳回。 |
| 轻量服务器仅作备案接入 | ✅ **可行且推荐**。买一台腾讯云轻量应用服务器（大陆节点、最低配）仅作备案接入，**业务流量仍走 Vercel + EdgeOne 全球节点**，不转移业务。备案通过后可将解析切回 EdgeOne。 |
| 接入商 vs EdgeOne 关系 | 腾讯云 = ICP 备案**接入商**（负责初审 + 提交管局）；EdgeOne = 加速/安全层（备案后切换加速区域）。二者独立；EdgeOne 本身不是备案接入商，但「加速区域含大陆时」要求域名已备案。 |
| ⚠️ 重大坑：IP 核查 | 工信部会定期 IP 核查，**若备案后域名长期解析到境外 IP，可能注销备案**。因此备案通过后应尽快执行线 B（EdgeOne 切境内加速），使域名有境内可达节点；或至少保持轻量服务器作为接入并长期有境内 IP 解析记录（可在轻量服务器放一个简单可达页面/用其做备案接入并保持解析）。 |

**三列分工（B2）：**

| 【用户必须亲自准备/操作】 | 【可由团队(主理人+工程师)代劳】 | 【注意点与坑】 |
|---|---|---|
| 购买腾讯云轻量应用服务器（大陆节点、最低配）用于备案接入（需实名认证腾讯云账号）。 | 在腾讯云控制台发起备案、填写主体/网站信息、上传材料、对接初审。 | 不可用 Vercel/境外服务器直接备案；备案后若长期解析回纯境外 IP 会被注销——务必接好线 B 或保留境内解析。 |
| 在腾讯云完成账号实名（个人）。 | 备案通过后协助将域名解析从"仅全球节点"切到含大陆加速（见 B4）。 | 轻量服务器仅作接入，但需保证备案期间及之后有稳定境内 IP 解析，避免被核查注销。 |

## B3 备案与抖音白名单的关系

| 维度 | 结论 |
|---|---|
| 抖音白名单是否要求域名已备案 | 抖音 request 合法域名白名单**仅校验域名 HTTPS 可达性 + 在白名单内，不强制要求已完成工信部 ICP 备案**。当前 `kejingbbao.cn` 已加白名单 + EdgeOne「全球可用区(不含中国大陆)」免备案可正常运行。 |
| 平台游戏备案/ICP 核准 | 是游戏主体级合规，通常要求游戏所调用境内网络服务域名合法合规；且境内加速（线 B）本身要求域名已备案。 |
| 未备案能否先上线 | ✅ **线 A 可独立推进**（仅全球节点加速）。⚠️ 但线 B（境内加速）必须完成域名 ICP 备案；为降低合规风险，建议线 A 也完成域名备案（尤其未来若接内购/实名/广告需更强合规）。**需以抖音开放平台/管局最新答复为准**。 |

**三列分工（B3）：**

| 【用户必须亲自准备/操作】 | 【可由团队(主理人+工程师)代劳】 | 【注意点与坑】 |
|---|---|---|
| 决策：线 A 是否先以"免备案全球节点"上线，还是等备案一起上。 | 评估白名单与备案的衔接，确保切境内加速后域名仍可达。 | 不要误以为"已加抖音白名单=已备案"；白名单与工信部备案是两件事。 |

## B4 备案后 EdgeOne 切境内加速（前提与步骤）

**前提：** 域名 `kejingbbao.cn` 已完成工信部 ICP 备案（取得备案号）。

**步骤：**
1. 腾讯云备案接入成功，取得 ICP 备案号。
2. 登录 EdgeOne 控制台 → 站点 → 修改「加速区域」：由「全球可用区(不含中国大陆)」改为「中国大陆可用区」或「全球可用区(含中国大陆)」。
3. 源站仍填 `cname.vercel-dns.com`（Vercel 提供的 CNAME 源站）；回源协议建议 HTTPS。
4. DNSPod 解析：当前 `@` 记录（CNAME）指向 EdgeOne 分配地址；切换加速区域**通常无需改 DNS 记录**（EdgeOne 按站点配置路由），保留 `@` CNAME 即可。
5. 验证：`nslookup`/`dig` 确认解析到 EdgeOne 境内节点 IP；等待 DNS 生效（数分钟至 48h）。

**⚠️ 注意事项（坑）：**
- **跨境回源**：源站 Vercel 在境外，加速区域含大陆时，用户→EdgeOne 境内节点→跨境回源 Vercel，**回源延迟较高、效果不保障**（官方明确）。建议：如追求境内稳定，应将部分源站迁至境内（如腾讯云轻量/云函数），或采用 EdgeOne「跨地域安全加速(海外站点)」方案。
- 若 `@` 是 A 记录直指境外 IP，需改为 CNAME 指向 EdgeOne（当前已是 CNAME，OK）。
- 加速区域含大陆后，EdgeOne 会要求域名已备案——**务必先备案再切**。

**三列分工（B4）：**

| 【用户必须亲自准备/操作】 | 【可由团队(主理人+工程师)代劳】 | 【注意点与坑】 |
|---|---|---|
| 确认备案号已取得，授权团队操作 EdgeOne。 | 在 EdgeOne 控制台切换加速区域、保留 Vercel CNAME 源站、验证境内解析。 | 跨境回源延迟问题：纯境外源站 + 境内加速，回源质量不保障，境内"快"主要体现在边缘命中，动态对战回源仍可能慢。 |
| — | 监控切换后国内访问质量，必要时建议迁部分源站至境内。 | 未备案就切含大陆加速区域会被 EdgeOne 拦截/要求补备案。 |
